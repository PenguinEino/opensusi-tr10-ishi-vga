# アニメーション版の抽出SPICE検証

最終GDSから直接再抽出した **1990素子の回路をngspiceで実行し、20試験・922クロックすべて合格**しました。GDS SHA256は `95a799066aeade8a5ca04cd1425252759988ee61c429f383c699b1b17e4d29b3` です。

[集約結果](simulation/summary.json) · [抽出・変換の監査](simulation/extraction_manifest.json) · [ngspice用回路](simulation/core_sim.spice)

| 試験 | 内容 | 照合クロック |
|---|---|---:|
| `stage_0`〜`stage_4` | I／S／H／I／発光なし、それぞれ上側の1行とHSYNC | 100×5 |
| `lower` | 下側の文字・配線・色境界 | 100 |
| `vsync` | VSYNC開始、2行のLow、終了 | 210 |
| `phase_000`〜`phase_127`の12ケース | フレーム末でのphase加算、桁上がり、文字切替、休止への移行、127→0 | 4×12 |
| `powerup` | FFの状態指定なし、VDDの0→5 Vランプ | 64 |
| **合計** | **20試験** | **922** |

phaseの境界試験は0、1、3、7、15、31、47、63、79、95、111、127から開始しました。各クロックでh/v/phaseの24 bitとRGB／HS／VSの5 bitを、凍結した全h/v状態の参照表と独立した発光条件へ照合しています。

条件はngspice 46+、PDK既定モデル、5 V・27℃、3.15 MHz、CLK立上り／立下り2 ns、各出力1 pF、積分法trap、最大刻み1 nsです。立上り開始150 ns後を採点し、1.5 V未満をLow、3.5 V超をHigh、その間は不合格にします。

境界試験はh/v/phaseのFFのQとQBへ初期条件を与え、時刻0で解放します。電源投入試験はFFの初期条件を指定せず、`.tran ... uic`、0.1〜1.1 µsでVDDを0→5 V、2 µsからCLKを入力。96クロック中、最初の32を除く64クロックを照合しました。これは電源立上り1条件の短い観測区間です。

抽出はno-combineで、接続・素子寸法・拡散容量を保持しています。金属配線RCを含むPEX、PVT sweep、実パッドやVGAケーブル負荷は含みません。2.13秒の全アニメーション周期の一致は、別途実施した128フレームのRTL／ゲート検証によるものです。READMEのシミュレーションGIFもゲート波形から作っています。

刺激・ログ・生波形のgzip・サンプル・個別判定は `simulation/<試験名>/` に保存しています。[再判定・再実行](REPRODUCE.md)ができます。
