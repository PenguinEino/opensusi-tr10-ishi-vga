# ISHI VGA仕様

## 基本仕様

| 項目 | 値 |
|---|---|
| 機能 | ISHIロゴ「格子＋5線：電源枝」の静止画を出力 |
| 電源 | VDD=5 V、VSS=0 V |
| CLK | 外部入力3.15 MHz、立上りで更新。リング発振器なし |
| 映像 | 640×480・60 Hz相当、RGB111、HSYNC／VSYNC負極性 |
| 水平 | 100クロック／行、1クロック=8画素時間 |
| 垂直 | 525行／フレーム |
| RESET | なし |
| 端子数 | 6信号＋VDD＋共通VSS=8電気端子。共通VSSを除き7端子 |
| コア寸法 | 1792.8×897.2 µm（1.6085 mm²） |
| 割当予算 | 1800×900 µm |
| GDSトップ／DBU | `ishi_vga_core`／0.001 µm |
| GDS bbox | 左下(-15.3, 0)、右上(1777.5, 897.2) µm |
| 論理セル | 209セル、セル面積301,193 µm² |
| 配置インスタンス | 論理209＋TAP 20＋FILL2 15＋FILL3 101=345 |
| 使用スタセル | APRtools **v59_4**。PDKの同名スタセルやv64_8とは別物 |

寸法は端子引き出しを含むコアbbox。枠に対する横7.2 µm、縦2.8 µmの差は、フレーム配線の余白を確保済みという意味ではありません。GDSの原点はbbox左下と一致しません。左端をX=0へ合わせるなら、コア配置のXを+15.3 µmにしてください。

## 端子

以下はコア端子の位置で、パッド番号ではありません。単位µm、GDS座標をそのまま記載。M1=13/0、M2=20/0。端子名は小文字。

| 端子 | 方向・機能 | 層 | X | Y | 接続位置 |
|---|---|---|---:|---:|---|
| `clk` | 入力、立上りクロック | M2 | 844.2 | 895.5 | 上辺 |
| `vsync` | 出力、負極性垂直同期 | M2 | 974.7 | 895.5 | 上辺 |
| `hsync` | 出力、負極性水平同期 | M2 | 261.9 | 1.8 | 下辺 |
| `r` | 出力、赤1 bit | M1 | -14.4 | 690.3 | 左辺 |
| `g` | 出力、緑1 bit | M1 | -14.4 | 693.9 | 左辺 |
| `b` | 出力、青1 bit | M1 | -14.4 | 601.2 | 左辺 |
| `vdd` | 電源、5 V | M1 | 2.7 | 132.0 | 電源レール上 |
| `vss` | 共通接地、0 V | M1 | 2.7 | 77.3 | 電源レール上 |

VDD/VSSの座標はレール上の注記点で、信号と同じ外周引き出しではありません。統合側で各電源レールへ接続してください。

![実配線上の端子位置と各端子の拡大図。青はM1、金はM2、赤丸が接続点](ishi_vga_pins.png)

下段は各端子を中心とした24×24 µmの拡大図です。数値はGDS座標で、電源2点も含めた8端子を実メタル図形・GDSの注記と照合しています。

## 走査タイミング

| 区間 | 水平クロック数 | VGA画素時間換算 | 垂直行数 |
|---|---:|---:|---:|
| 表示 | 80 | 640 | 480 |
| フロントポーチ | 2 | 16 | 10 |
| 同期Low | 12 | 96 | 2 |
| バックポーチ | 6 | 48 | 33 |
| 合計 | 100 | 800 | 525 |

水平31.5 kHz、1行31.746 µs、垂直60 Hz、1フレーム16.667 ms。RGBとHS/VSは同じクロックでレジスタ出力します。帰線中RGBは黒です。

実装上の水平カウンタは7 bitで `71→70→…→0→127→…→100→71`。画面上の水平位置は `(71-h) mod 128`。行末の `h=100` で垂直カウンタを更新します。

垂直カウンタは10 bitで `500→501→…→1023→0→500`。画面上の行は `(v-500) mod 1024`。HSYNCは更新前の `106≤h<118`、VSYNCは `990≤v<992` でLow。出力は更新前のh/vに対応するため、RGB・同期を一緒に解釈してください。

表示図案の有色部分の外接範囲は画面の `[64,576)×[92,412)`、512×320画素。横の変化は8画素単位です。旧128×108・RGB222・6.3 MHz案とは異なります。

| RGBコード | 色 |
|---|---|
| 000 | 黒（背景・帰線） |
| 001 | 青 |
| 011 | 水色 |
| 100 | 赤 |
| 101 | 紫 |

画像ROMは使いません。座標から文字・横帯・電源枝5本を判定し、固定の5色へ割り当てます。「電源枝」は表示するロゴの図案を指し、チップ内部の電源配線本数ではありません。

## 起動と接続

VDDを安定させ、0～5 VのCLKを入力します。3.3 V GPIOからの直接駆動を前提とせず、5 VセルのBUFTH入力に適合させてください。旧6.3 MHzを入れると走査周波数が2倍になります。

RESETがないため、投入直後の画像・同期は未定義です。h/vの全131,072二値状態を調べた遷移モデルでは、すべてが52,500クロックの単一周期へ入り、周期への到達は最大49,928クロック（約15.85 ms）でした。これはアナログ起動保証ではなく、モニタの同期獲得時間も含みません。

RGB／HS／VSはデジタル出力です。**75 ΩのVGA終端をコアセルで直接駆動しません。** 統合フレームのI/O回路と、電圧に適合する外部バッファ・RGB111用抵抗DACを使います。SPICEの出力負荷1 pFは仮定であり、ケーブル・基板・外部入力負荷の確定値ではありません。

## 検証

| 項目 | 結果と範囲 |
|---|---|
| 固定版チェック | APRtools／PDK／v59_4資産・記録済みPCellパッチ一致。回路検証とは別 |
| 描画DRC | 0件 |
| マスクMDP検査 | **WAR06 Floating SG 1件残存**。CLKのBUFTH入力。ESD未接続 |
| strict LVS | 全回路一致、トップ8端子一致 |
| 独立した接続監査 | 信号696端子、欠落・短絡・断線0。VDD/VSS各1成分、相互に分離 |
| RTL／ゲート | 同期獲得後2フレーム、各105,000 tickのRGBとHS/VSが全一致。試験側でFFを0初期化、ゲートは単位遅延モデル |
| 二値起動モデル | 全131,072カウンタ状態を探索。上述の単一周期へ到達 |
| セル遅延STA | typ 5 V/25℃、周期317.460317 ns、reg→reg setup余裕275.957 ns、hold余裕6.634 ns |
| 抽出SPICE | 5 V/27℃、3.15 MHz、立上り・立下り2 ns、出力各1 pF。5試験・計668クロックで状態17 bitと出力5 bitが一致 |
| SPICE参照回路 | 独立LVS参照回路の上側帯110クロックも一致。抽出668クロックとは別集計 |
| GDS再現 | 凍結したAPR出力から局所修復・注記・引き出しを再実行し、4段階のGDSがバイト一致 |

抽出は最終GDSに `klayout_extract.py --no-combine` を適用。1774素子のW/L・拡散面積／周長を保ち、識別子だけをngspice向けに変換しています。VDD/VSSを含む端子順は抽出結果から読み取っています。

SPICEはngspice 46+、SPARSE 1.3、既定許容差、`trap`、最大刻み1 ns。CLK立上り開始の150 ns後、1.5 V未満をLow、3.5 V超をHighとして照合しました。観測した出力遷移の最大CLK→出力50%遅延は約19.118 nsですが、全経路の最悪値やFmaxではありません。

| 抽出試験 | 条件 | 照合クロック |
|---|---|---:|
| `upper_init` | h=71、v=672から上側帯・電源枝・HSYNC | 110 |
| `lower_init` | h=71、v=816から下側帯・切れ目・HSYNC | 110 |
| `vsync_init` | h=103、v=989からVSYNCの開始・2行Low・終了 | 210 |
| `frame_wrap_init` | h=103、v=1023から1023→0→500 | 110 |
| `powerup` | FFの.icなし、ゼロ初期値からVDDを0.1～1.1 µsで0→5 V、CLKは2 µs開始 | 128 |

境界4試験はFFのQ/QBを `.ic` で指定し時刻0に解放。電源投入試験は `.tran ... uic` で160クロックを解析し、最初の32を除いた128を照合しています。任意のアナログ初期状態からの起動を証明していません。

**未実施：** 配線RCを含むPEX、全フレームのアナログ過渡解析、PVT sweep、実パッド・基板負荷、実モニタ確認。フレーム統合と残るFloating SG警告の解消も未実施です。

## 統合側へ渡す事項

使用する主催者フレームとパッド番号は未確定です。固定ツール内の `OSS_FRAME_GIO` と主催者のアナログ `OSS_FRAME` は同一ではありません。現GDSにどちらのフレームも入っていません。

GDSには `ishi_vga_core` のほかに、REG8x16等の未参照ライブラリtopセルが11個残っています。検証済みGDSのバイト一致を保つため残したもので、VGAの使用回路ではありません。**統合時は `ishi_vga_core` を明示選択し、GDSの全topセルを一括配置しないでください。**

統合時はbboxの負のX座標、電源レール、I/Oの駆動・入力電圧、ESD接続を合わせ、全体でDRC／MDP／strict LVSを再実行してください。現時点でFloating SG警告の消滅を保証しません。
