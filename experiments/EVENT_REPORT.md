# B-image event-driven RGB experiments

Generated by `scripts/event_generate.py` from the ordered painter in
`scripts/reference_frame.py`, `assets/logo_rectangles.json`, and palette
`[63, 27, 53, 31, 23, 43]`. The event state starts white at active-line h=0,
turns black at h=160, and applies only the per-pixel bit transitions for
h=1..159. Vertical blanking forces black. h80 candidates translate the
horizontal counter comparisons modulo 256 while keeping the external scan
sequence unchanged. No root RTL, `config.py`, or `out/` file was modified.

## Results

Areas below are the final BUFTH-inserted netlist figures from the pinned
v59_4 flow. STA uses the design's configured 155 ns period (6.45 MHz).

| Candidate | Cells (FF / comb.) | Area (µm²) | STA reg→reg slack | STA reg→out slack | Verification |
|---|---:|---:|---:|---:|---|
| setclear h0 | 359 (28 / 331) | 490,441 | 111.474 ns | 117.271 ns | PASS |
| setclear h80 | 360 (28 / 332) | 487,234 | 114.740 ns | 117.271 ns | PASS |
| toggle h0 | 351 (28 / 323) | **474,403** | 112.443 ns | 116.406 ns | PASS |
| toggle h80 | 356 (28 / 328) | 484,026 | 111.813 ns | 116.406 ns | PASS |

The smallest result is toggle h0: 20,849 µm² (4.21%) below the current B
baseline's 495,252 µm², with 24 fewer cells. That is a synthesis-area
comparison only; placement, routing, DRC, and LVS have not been run for these
candidates. STA is pre-route, and gate simulation uses unit delays.

`python3 scripts/event_test.py` checked RTL and final `out/ishi_vga_core_pnr.v`
for all four candidates at 6.30 and 6.45 MHz. Each check compared 315,017
time-ordered output ticks against `tests/expected_frame.hex`, including frame
wrap, stopped-clock reset, and synchronized reset release; every dump matched
byte for byte. The output includes RGB and both sync signals. The per-run
source hashes and logs are in each candidate's `build/verification.json` and
`build/verification.log`.

## Reproduction

```sh
python3 scripts/check_toolchain.py
python3 scripts/event_generate.py
python3 scripts/run_apr.py --design-root experiments/event_toggle_h0 syn/syn.sh
python3 scripts/event_test.py
```

The other three candidates use the same `syn/syn.sh` entry point with their
own experiment directory. Run synthesis one candidate at a time. The pinned
upstream flow inserted two BUFTH cells on the external `clk` and `reset_n`
inputs in each run; no internal BUFTH was observed.
