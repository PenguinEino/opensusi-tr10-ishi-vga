# Reverse horizontal counter experiments

Four horizontal-counter variants and one combined h79/v+500 variant of the
current B design were generated by `scripts/descending_generate.py`. Each
uses the original B `ishi_logo` color
masks and priority, RGB/HS/VS output registers, reset pipeline, and vertical
counter. The horizontal counter starts at 159, 199, 255, or 79, decrements
each tick, and resets to its start at `(start - 199) mod 256`. Screen and logo
intervals were translated at generation time; the RTL contains no coordinate
subtractor. When a transformed interval ends at 256, its upper-bound test is
omitted (for example start=255 active h is `h >= 96`).

## Results

The areas are from the final BUFTH-inserted netlist using the pinned APRtools
and v59_4 flow. STA is pre-route at the configured 155 ns period.

| Start | Final cells (FF / comb.) | Area (µm²) | STA reg→reg slack | STA reg→out slack | Verification |
|---:|---:|---:|---:|---:|---|
| 159 | 333 (28 / 305) | 462,534 | 114.937 ns | 118.194 ns | PASS |
| 199 | 383 (28 / 355) | 509,366 | 110.514 ns | 118.194 ns | PASS |
| 255 | 335 (28 / 307) | 460,290 | 114.991 ns | 118.194 ns | PASS |
| 79 | 317 (28 / 289) | **440,402** | 112.030 ns | 118.194 ns | PASS |
| 79, with vertical +500 | 282 (28 / 254) | **407,684** | 112.976 ns | 118.194 ns | PASS |

The combined start=79 / vertical+500 candidate is the smallest: 87,568 µm²
(17.68%) below the current B baseline of 495,252 µm². The horizontal-only
start=79 candidate is 54,850 µm² (11.07%) below baseline. The combined
candidate has not had placement, routing, DRC, or LVS run as part of this
experiment. The STA result is pre-route; gate simulation uses unit delays.

`python3 scripts/descending_test.py` checked RTL and final
`out/ishi_vga_core_pnr.v` for each variant at 6.30 and 6.45 MHz. Every run
compared 315,017 time-ordered output ticks to `tests/expected_frame.hex`,
including frame wrap, stopped-clock reset, and synchronized release. All
RGB/HS/VS dumps matched byte for byte. Per-run source hashes and logs are in
each candidate's `build/verification.json` and `build/verification.log`.

The pinned flow inserted only the two expected input BUFTH cells for `clk`
and `reset_n`; no candidate was blocked by an internal BUFTH.

## Reproduction

```sh
python3 scripts/check_toolchain.py
python3 scripts/descending_generate.py
python3 scripts/run_apr.py --design-root experiments/descending_h79_v500 syn/syn.sh
python3 scripts/descending_test.py
```

The other four synthesis results use the same `syn/syn.sh` entry point with
their own experiment directory.
