# 現在の信号数・クロック方針

**現採用版は格子＋電源枝5本、VDD、CLK、HSYNC、VSYNC、R、G、Bの7本（共通VSSを除く）。外部CLKは3.15 MHz、RGB111、RESETなし、リングなし。** [完成したコアの端子座標・実装記録](POWER_GRID_IMPLEMENTATION.md)。1792.8×897.2 µmで端子引き出し済み、描画DRC 0、strict LVS合格。フレームのピン番号は統合保留のため未確定。

**以下は以前のA/B保存版の履歴。** 下表の10信号や6.30 MHzは現採用版に適用しない。

[Aの形を維持する追加試験](HALF_A_FEASIBILITY.md)もこの7本で機能検証したが、1800×900 µmには未達。AのCLKは6.30 MHz、前回の格子版は3.15 MHzなので取り違えない。RESETはどちらにもない。

過去の [ピン削減レビュー](PIN_REDUCTION_REVIEW.md) ではRESET省略・RGB221/121を検討した。これらの配色案は採用せず、上記のRGB111・RESETなしを採用した。下表は旧実装の本数。

2026-09-25の最新ユーザー指示「リングおしれーた搭載は諦める」を反映。**外部CLKだけを使い、リング発振器は搭載しない。** フレーム統合はユーザー指示で停止中。

|用途|本数|
|---|---:|
|RGB222（R1/R0/G1/G0/B1/B0）|6|
|HSYNC / VSYNC|2|
|外部CLK|1|
|RESET（active low）|1|
|信号合計|**10**|
|VDD / VSS|2|
|使用する端子の合計|**12**|

主催者の「共通VSSを除く」数え方なら **11本**。A案とB案で同じ。物理パッケージ全体の端子数とは区別する。取得済みテンプレート自体には信号パッド14個＋電源2個があり、全てを使用する必要はない。最終のパッド番号・ボンディング割当は統合再開時に確定する。

CLKには基準6.30 MHzを外部から与える。リング出力端子と、リングからCLKへ戻すジャンパは不要。任意追加のリングを含めていた過去の検討より、使用する信号数が1本少なくなる。リセット入力は維持する。

既存のB確定コアと今回のA試験は、いずれも `MACRO_MODE='none'` / `RING_OSC_ORIGIN=None` で、リングはもともとGDSへ搭載されていない。この取りやめによって、測定済みコアの寸法がさらに縮むわけではない。

再現性を保つため、既存試験のハッシュに含まれる `config.py` は書き換えない。そこでの `PAD_MAP[12]` の `reserved for ring output` は過去の未使用予約であり、現在の採用仕様ではない。新たに実装する最終ラッパでは未使用として扱う。外部CLKとRESETの電圧条件は採用セルの条件に従う。
