# ピン削減とスタセル実装の説明

2026-09-25。ユーザーとの検討記録。**以下のRGB縮小・RESET省略は未採用の候補**。現在のA/B成果物はRGB222＋RESETのまま。[確定ピン仕様](PIN_PLAN.md)。フレーム統合は停止中、リング発振器は不搭載。

## 使用セルと自動化の範囲

採用は岡村さんのAPRtools `stdcell/v59_4`。TR-1um向けの自作セルレイアウトで、PDK同梱の同名 `TR-1um_STDCELL.gds` とは別物。回路図の出典はPDKの `libs.tech/xschem/TR-1um_5_stdcell` と上流READMEに明記されている。「TR-1um用ではない」「回路図まで完全に独立したライブラリ」とは説明しない。

スタセル自体のレイアウトは手描きだが、今回のVGA回路はVerilogからYosys/ABCで論理合成し、固定v59_4へマッピングしている。配置・配線も自動処理。最新Aでは設計側の焼きなまし探索でセルの行割当を改善し、固定APRtoolsの未変更の行内順序最適化・行詰め・GDS出力・配線を利用した。単なる手置きでも、上流既定設定だけの実行でもない。

セルの由来は [上流v59_4 README](../tools/APRtools/stdcell/v59_4/README.md)。同READMEの古いPNR派生物の採用記述は使わず、実際の採用パス・コミットは [APRTOOLS_ADOPTION.md](APRTOOLS_ADOPTION.md) と [toolchain.lock.json](../toolchain.lock.json) を参照する。

## RESET端子の削除

この回路は外部へ特定の初期フレーム位相を約束する必要がないため、RESET省略は可能な設計候補。現在の `reset_pipe` / `running` に依存した起動を取り除き、カウンタを無条件に回して任意の二値初期状態から正しい周期へ入る構成に変更する。

現行Aの横カウンタは8 bit減算、120で63へ戻る。縦は行末に10 bit加算、0で500へ戻る。この遷移は任意の二値状態から正しい200 tick／525行の周期へ復帰できる。出力レジスタも毎クロック上書きする。単に既存RESET端子を浮かせる／削除するだけではない。`initial` 値やFPGA固有の電源投入初期化には依存しない。

実装時は任意初期状態からの到達性と、復帰後の全画素・同期信号を検証する。電源・CLKが安定するまでの表示や同期位相は保証しない。アナログな電源投入過渡の検証済みという意味ではない。RESET削除版はまだ合成・配置配線していない。

## RGB各チャンネルを直接減らす

外部パレットデコーダは使わず、チップのR/G/B信号をそれぞれ抵抗DACへ接続する。RGB121はR=1 bit、G=2 bit、B=1 bitの意味。

|方式|RGB信号|RESETなしの全信号数（RGB＋HS＋VS＋CLK）|VDD/VSS込み|共通VSSを数えずVDDを含む本数|
|---|---:|---:|---:|---:|
|RGB222|6|9|11|10|
|RGB221|5|8|10|9|
|RGB121|4|7|9|8|
|RGB111|3|6|8|7|

RESETを残す場合は各合計に1を足す。「7信号」と「主催者枠の7ピン」は電源の数え方が異なる。最終のパッド割当は未確定。

現行パレットの青系3色はR=1、B=3で、Gが1/2/3と変わる。そこでGだけ2 bitを維持すると、青系3色の違いを残せる。

|色|現行RGB222の8 bit表示値|RGB121の8 bit表示値（各1 bitはMSB）|
|---|---|---|
|白|255,255,255|255,255,255|
|青|85,170,255|0,170,255|
|赤文字|255,85,85|255,85,0|
|水色|85,255,255|0,255,255|
|濃い青|85,85,255|0,85,255|
|薄紫|170,170,255|255,170,255|

- RGB221はBを1 bitへ。現行パレットでは赤文字のBだけが変わり、オレンジ寄りになる。赤のGも0へ調整する案がある。
- RGB121はR/Bを1 bitへ。形と6色の区別を維持するが、色味は変わる。赤文字のGを0にする別案も生成した。
- RGB111を単純に上位bit化すると、今回の6色が4色に潰れる。別の色を割り当てれば6色の区別自体は可能だが、青系3段階の再現はできず、配色を大きく変える。

1 bitのチャンネルも黒からフルスケールまで出せる抵抗値へ設計し直す。2 bit DACの抵抗を1本外すだけでは振幅が変わる。ASIC側の出力バッファとモニタ終端を含む抵抗設計は必要だが、外部の色番号デコーダは不要。

[比較画像](../samples/a_channel_bits/comparison.png) を `xdg-open samples/a_channel_bits/comparison.png` で開く。生成器は [preview_a_channel_bits.py](../scripts/preview_a_channel_bits.py)、数値とSHA256は [manifest.json](../samples/a_channel_bits/manifest.json)。訂正Aの37矩形をそのまま描画した設計参考画像であり、RTLシミュレーション出力ではない。元の画像・パレット・RTLは書き換えていない。

RESETと色bitの削減は出力FF・リセット配線・一部色判定の削減候補だが、矩形判定と走査カウンタは残る。ピン数の削減率をそのまま配線後面積へ適用しない。半枠に収まるかは別の合成・配置配線結果が必要。
