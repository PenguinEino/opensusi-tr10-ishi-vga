# 半枠・7ピンへの再設計

**後続で格子＋電源枝5本が採用され、コアを1792.8×897.2 µmで完成した。** [現行の実装・提出セット](POWER_GRID_IMPLEMENTATION.md)。以下の未採用／未完成の記述と測定値は比較時の記録として保存する。

**後続のユーザー指示で、Aの形を残した半枠化を優先して再試験した。** [追加結果](HALF_A_FEASIBILITY.md)は最小診断GDS1783.8×1717.7 µmで未達。本書の格子版は元Aと異なる、未採用の比較候補として保存する。

2026-09-25のユーザー指示「面積半分、ピンも７つ」を優先する。**作業上の予算は1800×900 µm、VDDを含み共通VSSを除く7本**。主催者の最終割当が確定したという意味ではなく、元の1800角の半分を厳しく見た目標。フレーム統合は停止中、リング発振器は不搭載。作業は主エージェント1人。

推奨候補は **RGB111・外部RESETなし・黒背景・規則的な格子へ描き直したISHI文字**。従来A/Bの図形や配色と完全一致する案ではない。候補の見た目は未承認で、既存A/B成果物は変更していない。

## ピンとタイミング

|用途|本数|
|---|---:|
|VDD|1|
|外部CLK|1|
|HSYNC、VSYNC|2|
|R、G、B（各1 bit）|3|
|共通VSSを除く合計|**7**|
|VSSも含む電気端子数|8|

RGBは色番号ではなく直接のデジタル色信号。外部パレットデコーダは不要。外付けの出力バッファと各色1本の抵抗でVGAへ接続する。既存RGB222 DACから抵抗を適当に抜くのではなく、1 bit用の振幅へ設計する。

推奨候補のCLKは **3.15 MHz**。1 tickが横8画素時間、1行100 tick（表示80、前2、同期12、後6）、縦525行。640×480・60 Hz相当の同期を維持する。旧6.3 MHzをそのまま入力すると走査周波数が2倍になるため、FPGA試験用クロックも変更する。[標準タイミングの参照](https://projectf.io/posts/video-timings-vga-720p-1080p/)。

RESET端子と解除同期FFを削除し、全レジスタをクロックで更新する。横は7 bit減算、100で71へ戻る。縦は行末に10 bit加算、0で500へ戻る。二値状態の遷移モデルでは、任意のh/v初期値から100 tick×525行の周期へ戻る。モデル全状態を調べた保守的な復帰上限は50,029 tick、3.15 MHzで約15.9 ms。[遷移モデル検査](half_slot_startup.json)。RTLに `initial` や電源投入値は入れていない。

RTLと最終BUFTH挿入後ゲートモデルは、試験側から初期状態を0へ設定し、同期獲得後の2フレーム全tickを独立画像と照合した。これは任意状態をRTLで形式検証した結果でも、電源のアナログ立上りを検証した結果でもない。モニタの同期獲得時間も未測定。

## 比較した7構成

全てRGB111・RESETなし。セル面積は配線・TAP/FILLを含まない。

|図形・背景|論理セル|セル面積 µm²|配置探索後の診断GDS µm|
|---|---:|---:|---:|
|Aの図形128×108、白|371|482,743|未配線|
|Aを64×54へ丸める、白|431|547,217|未配線|
|Bの図形128×108、白|290|399,666|1783.8×1340.4|
|Bを64×54へ丸める、白|324|425,327|未配線|
|Bの図形128×108、黒|256|356,363|1783.8×1119.7|
|文字を格子へ描き直す、白|213|301,514|1783.8×1000.9|
|**文字を格子へ描き直す、黒**|**176**|**267,192**|**1783.8×758.6**|

64×54版はこの座標丸め・V488カウンタ実装では増えた。解像度を下げれば常に増えるという一般的な結論ではない。未探索の符号化もある。今回の比較では、解像度や出力bit数だけを下げるより、規則的な字形と黒背景の効果が大きかった。

格子版は4文字を同じ幅の区画に割り当て、左右のIを同じ字形として扱う。8×7の字形表から小さい論理式を生成する。黒背景では表示外も同じ黒なので、白背景を作る有効表示区間の判定を省ける。赤・水色・青・紫の4色を黒背景へ描く。線の太さ、文字の配置、色は元ロゴと変わる。

白い格子版の3行配置は、必要セル幅5076.0 µmに対し実効4762.8 µmで不足して停止。4行へ変更した。黒い格子版は4498.2 µmとなり3行で置けた。この段差も配線後寸法の差に効いている。

通常配置と行割当の焼きなまし探索の両方を測定した。探索のseed11、8再開×2,000,000試行、その他設定は各 `ROW_OPT` に固定。一般的な最小面積を証明した比較ではない。
